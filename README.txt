# Para Sofía ♡

Sitio de cumpleaños estático hecho con HTML, CSS, Bootstrap y JavaScript.

## Probarlo localmente
1. Descarga y descomprime la carpeta.
2. Abre `index.html` en un navegador. Se necesita conexión a Internet para cargar Bootstrap y la fuente web.
3. Prueba botones, navegación y vista móvil.

## Publicarlo con GitHub Pages
1. Crea un repositorio público en GitHub, por ejemplo `para-sofia`.
2. Sube `index.html`, `style.css` y `script.js` a la raíz del repositorio.
3. En el repositorio entra a **Settings → Pages**.
4. En **Build and deployment**, elige **Deploy from a branch**.
5. Selecciona `main` y la carpeta `/(root)`, y guarda.
6. Espera a que GitHub Pages publique la web; el enlace aparecerá en esa misma sección.

## Antes de enviárselo
- Revisa el texto de la indirecta y asegúrate de que encaja con la conversación real que tuvieron.
- Prueba el enlace desde tu celular o una ventana privada.
- La música no se reproduce automáticamente: el botón abre una búsqueda de la canción en YouTube.
- Los recursos visuales son ilustraciones CSS/emoji y no incluyen imágenes oficiales de Hello Kitty.
